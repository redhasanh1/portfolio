01 Selected work

Capstone · 2026

PINN Humanoid

Live ↗ Code ↗

A full size, 3D printed humanoid robot that learns to move from physics simulation instead of hand coded motion, built from scratch as a final year capstone.

Most student robotics projects hand code every motion. I wanted the robot to learn its own physics instead, so every skill starts as a blank neural network trained in simulation before it ever touches real motors. I implemented physics informed neural networks (PINNs) that fold physics based loss terms directly into training, which cut the amount of real data needed for sim to real transfer and made trajectory prediction and plan validation noticeably more reliable. On top of that I built a real time ball catching controller that predicts object trajectories from physics aware motion models, and wired up ESP32 microcontrollers to drive finger level control and teleoperation of the robot's 3D printed hands, with an imitation learning policy layered on top for autonomous task execution.

  • Python
  • PyTorch
  • PINNs
  • ESP32 / C++
  • Imitation Learning
  • 3D Printing

iOS App · 2025 to 2026

ObjectRemoverAI

Code ↗

A native iOS app that removes any object from a video, frame by frame, in real time, with a custom CUDA kernel I wrote to make it fast enough to be usable.

Video object removal is normally too slow to feel like a product. I trained a custom YOLOv8 detector and integrated SAM2 for temporal mask tracking, then fed that into a ProPainter/RAFT inpainting pipeline so the background stays consistent frame to frame instead of flickering. The inference step was still the bottleneck, so I wrote a custom DCNv4 CUDA kernel as a TensorRT plugin targeting Ada Lovelace (SM 8.9), which cut inference latency 3x down to 7ms per frame versus the PyTorch baseline. To make it actually scale, I put the backend on a distributed worker cluster using Celery and Redis, load tested across GPUs from an RTX 3060 up to an RTX 5090 on Salad.com, and shipped the client as a native Swift iOS app through full App Store review, account creation, and authentication.

  • Swift / iOS
  • YOLOv8 / SAM2
  • CUDA / TensorRT
  • Celery / Redis
  • Distributed Systems

Full Stack Platform · 2025

RoomFinderAI

Live ↗ Code ↗

A rental marketplace with an AI agent that actually negotiates with landlords on your behalf, shipped as web, iOS, and Android apps.

I built the full stack myself: a Node.js 18 / Express 5 backend with Supabase (Postgres, Auth, Storage, Realtime) as the data layer, Stripe for subscription billing, and Google OAuth for sign in, alongside native companion apps in SwiftUI and Java/Android. The interesting engineering problem was keeping the AI negotiation engine online: it detects when it hits OpenAI rate limits and automatically fails over to Groq mid conversation, so negotiations stay live through provider outages instead of silently dying. It's deployed on Railway behind a Cloudflare Worker for edge routing, with Cloudflare Turnstile handling bot protection in front of the negotiation endpoints.

  • Node.js / Express
  • Supabase / Postgres
  • SwiftUI
  • Android / Java
  • Stripe
  • Cloudflare Workers
